# Feature Guide 01: Interactive ERD Diagram & Schema Visualizer

## Overview
The **Interactive ERD Diagram & Schema Visualizer** provides an in-app visual representation of SQL database tables, columns, primary keys, foreign keys, and entity relationships directly inside the desktop application. It eliminates the need for external diagramming software or manual database documentation tools.

---

## ⚠️ Problems & Challenges Solved

### 1. Hard-to-Understand Database Schemas
- **Problem**: When joining a project or managing legacy SQL Server databases, understanding foreign key relationships across dozens or hundreds of tables is difficult using SQL queries alone.
- **Impact**: Developers make mistakes in JOIN conditions, misunderstand data models, or break relational constraints.

### 2. Outdated & Low-Resolution Schema Documentation
- **Problem**: Traditional database diagrams generated by web tools or database management GUIs produce low-resolution, pixelated screenshots that look blurry when zoomed in or embedded in documentation.
- **Impact**: Unprofessional documentation, unreadable text on high-DPI displays.

### 3. Tedious Manual Diagram Generation for GitHub / Markdown READMEs
- **Problem**: Documenting schema structures for GitHub or GitLab repositories requires manually writing Mermaid syntax or uploading static images that quickly become outdated.
- **Impact**: Time wasted manually writing diagram syntax or maintaining out-of-sync image files.

---

## 🛠️ How Our Software Solves Them

### 1. Interactive Canvas with Pan, Zoom & Auto Layout
- **Pan & Zoom Controls**: Supports smooth zoom scaling (30% to 250%) using mouse scroll wheel or toolbar buttons (`+`, `-`, `Reset 100%`, `Fit to Screen`). Backdrop click-and-drag panning allows effortless navigation across large database schemas.
- **Draggable Table Cards**: Users can drag and reposition any table node across the canvas with real-time Bezier line recalculation.
- **Auto-Grid Engine**: One-click **Auto Layout** algorithm automatically arranges table nodes into a non-overlapping grid based on table count and column height.

### 2. Dynamic SVG Bezier Connector Lines
- Directional SVG Bezier curves connect Foreign Key source columns directly to Primary Key target columns.
- Connector lines include arrowhead markers (`#erd-arrow`) and highlight with bright accent colors when a table card is hovered or selected.

### 3. Multi-Format High-Resolution Export Suite
- **📷 High-Resolution PNG Photo Capture (`exportHighResPng`)**: Renders the complete ERD canvas on an HTML5 canvas at **2x device pixel density** (crisp high-DPI text & lines) and downloads `[Database]_ERD_HighRes.png`.
- **🎨 Scalable Vector SVG Export (`exportSvg`)**: Generates standalone vector `.svg` files that can be scaled infinitely without losing quality.
- **📝 Markdown Document Exporter (`exportMarkdownDoc`)**: Produces a full `.md` document containing:
  - Valid **Mermaid ERD** block (`erDiagram`) ready for GitHub/GitLab READMEs.
  - Formatted Markdown schema breakdown tables listing columns, types, nullability, PK, and FK constraints.
- **📋 Clipboard Mermaid Copy**: Copies raw Mermaid diagram syntax to the system clipboard in a single click.
- **🖨️ PDF & Print Support**: Styled print view formatted for exporting to PDF.

## 🔬 Technical Implementation Architecture

```
src/components/SchemaViewerModal.tsx
├── State Management
│   ├── zoomScale (0.3 to 2.5)
│   ├── panOffset ({ x, y })
│   ├── nodePositions (Record<tableName, { x, y }>)
│   └── activeTab ('columns' | 'data' | 'erd')
├── Rendering Pipeline
│   ├── HTML5 SVG Bezier Curve Engine (<path d="M... C..."/>)
│   ├── Interactive Canvas Overlay (Mouse Drag & Wheel Handlers)
│   └── 2x Pixel Density HTML5 Canvas Exporter
└── Metadata Source
    └── electron/runner.ts (sys.foreign_keys & sys.foreign_key_columns T-SQL query)
```
